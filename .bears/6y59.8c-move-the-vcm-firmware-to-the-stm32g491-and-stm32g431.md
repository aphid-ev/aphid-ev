## Summary
The minimal firmware in `ecus/vcm/firmware` targets the STM32F405RG and STM32F091CC. Retarget it to the chosen parts: a 512 KB STM32G491 (xE) for `main`, STM32G431 for `monitor`.

## Component
`ecus/vcm/firmware/{main,monitor}`, `ecus/vcm/README.md`, `rust-toolchain.toml`.

## Acceptance criteria
- [ ] `main` uses the embassy-stm32 feature for the G491 package the board uses (ask if it is not chosen yet), and `monitor` the G431's.
- [ ] Both build for `thumbv7em-none-eabihf` with matching probe-rs chips in `.cargo/config.toml`.
- [ ] `thumbv6m-none-eabi` is dropped from `rust-toolchain.toml` if nothing else needs it.
- [ ] `just vcm ci-firmware` passes.

## Verification
`just vcm ci-firmware`; the `main-firmware` and `monitor-firmware` wiki pages if they name the parts.
