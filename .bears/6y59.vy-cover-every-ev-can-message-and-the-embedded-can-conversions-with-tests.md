Found in the review of ncmh.z9. Gaps in `crates/ev-can/src/lib.rs` tests:
- `InverterTemperature` is only tested for rejection; no successful decode.
- `InverterStatus` current, rpm and error fields aren't pinned, so a swapped byte order would pass.
- `VcmKeepalive2` content isn't pinned (`keepalives_carry_their_crc` checks only its length, and the message has no CRC).
- `to_can` / `from_can` are untested, including rejection of remote and extended frames (`lib.rs:147-162`).

## Acceptance
- A pinned-byte test for each of the above, and round-trip plus rejection tests for the conversions.
- `just host ci` passes.
